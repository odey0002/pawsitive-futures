# Pawsitive Futures

A little corner of the internet for people who love animals and want to help them find a home.

Pawsitive Futures is a responsive animal rescue and adoption website where visitors can browse adoptable pets, learn about adoption, find pet-care resources, and explore ways to get involved through fostering, volunteering, donating, and events.

I originally built this as a school project, but I wasn't quite ready to leave it there. I came back to it later with a better idea of what I wanted the experience to feel like and started changing things, breaking things, fixing things, and generally making it much more "mine."

**What I Did

I worked on both sides of the project as the UI/UX Designer and Front-End Developer.

I planned the site's structure and user flows, designed the interface, wrote and refined the content, and then built the whole thing with HTML, CSS, and JavaScript.

The main user journeys I focused on were pretty simple:

Want to adopt? Find a pet → narrow down the options → learn about them → express interest.

Want to help in another way? Find out what's possible → choose volunteering, fostering, donating, or an event → take the next step.

I wanted the site to feel helpful without throwing a wall of information at someone the moment they landed on the homepage.

**A Bit of the Tech Story

Built with:

- HTML5
- CSS3
- Vanilla JavaScript
- Git & GitHub
- GitHub Pages
- Google Fonts
- VS Code

The project has actually gone through a bit of a journey.

In the original version, I experimented with Bootstrap. It was useful for getting things moving, but when I came back to the project, I wanted to understand and control more of what I was building.

So I gradually moved away from Bootstrap and rebuilt the interactive parts with **vanilla JavaScript**.

That meant I got to figure out things like the pet search and filters, result counts, the pet modal, mobile navigation, form feedback, and keyboard interactions myself instead of relying on a framework to do the work for me.

And yes, there was definitely some trial and error involved.

**The Fun Part: Making the Pets Actually Searchable

One of the things I wanted to improve was the adoption experience.

Instead of making someone scroll through a long list of animals and hope they find what they're looking for, I added search and filters for Dogs, Cats, and Rabbits.

The filters work alongside the search, update the number of results, give users a way to clear their search, and let them know when there aren't any matches.

Clicking a pet also opens a little information modal, with keyboard and Escape-key support built in.

**Making It Work on Smaller Screens

The desktop version was only part of the problem.

Once I started testing the site at smaller sizes, I found plenty of things that looked perfectly innocent on desktop and suddenly became a problem on mobile.

Filters were getting cramped. Some sections had too much breathing room. Some text was doing entirely too much. The footer needed attention. Things needed to stack differently.

So I went back through the pages and adjusted the layouts, spacing, typography, navigation, cards, filters, forms, and content for smaller screens.

The site is designed for desktop, tablet, and mobile, rather than treating mobile as an afterthought.

**A Little UX

The site is structured around five main areas:

"Home → Adopt → Get Involved → Resources → Contact"

I also spent time thinking about the people who might arrive at the site with completely different intentions. Someone ready to adopt needs a different path from someone who is just curious about fostering or wants to donate.

That was part of the reason I expanded the Get Involved section. It started out feeling more like a simple call-to-action, so I turned it into a proper place where visitors could actually understand their options before deciding what they wanted to do.

**Accessibility

I tried to make the site usable beyond just making it look nice.

That includes semantic HTML, meaningful image alt text, labelled form controls, keyboard-accessible interactions, visible focus states, skip navigation, and ARIA attributes where they were useful.

I haven't put the site through a formal WCAG audit, so I'm not going to pretend I have.

**What I Took Away From It

Honestly, the biggest lesson from this project was how different a website can become when you give yourself permission to come back and question your first decisions.

The first version got the job done. The version you're looking at now is much more intentional.

Revisiting it also gave me a chance to move beyond simply using tools and understand more of what was happening underneath. Moving from my earlier Bootstrap experiment to vanilla JavaScript was a big part of that.

There are still things I'd change if I kept working on it. That's probably a good thing.

**Where It Started

Pawsitive Futures began as an academic project during my Interactive Media Design program at Algonquin College.
I later brought it back, redesigned and expanded it as a personal project so I could push the original idea further and practice the combination of skills I'm most interested in: UX, visual design, and front-end development.
